# Superstore SQL Data Analysis
Data modeling and analysis of sales and profits from a superstore dataset in order to help market competitors to understand what works best for them.

## 📖 Project Overview

In this project, you:

1. **Create the database:** Building the database based on the Superstore free dataset
2. **Model the data:** facts and dimensions, ready for reports.
3. **Analyze it:** answer business questions with SQL.

## 🚀 Project Requirements

### Building the Database

#### Objective
Build the Superstore database using SQL Server to consolidate sales data, enabling analytical reporting and informed decision-making.


#### Specifications
- **Data Sources**: Import data from Superstore dataset provided as CSV files.
- **Data Quality**: Cleanse and resolve data quality issues prior to analysis.
- **Scope**: Focus on the latest dataset only; historization of data is not required.
- **Documentation**: Provide clear documentation of the data model to support both business stakeholders and analytics teams.

---

### BI: Analytics & Reporting (Data Analysis)

#### Objective
Develop SQL-based analytics to answer basic business questions about:
- **Sales Trends**
- **Customer Behavior**
- **Product Performance**


These insights empower stakeholders with key business metrics, enabling strategic decision-making.
